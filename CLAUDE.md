# CLAUDE.md

## Working with the CMO

A separate CMO agent handles marketing and analytics. GitHub issues labelled `needs-cmo` are the
shared channel.

- **To ask the CMO something or hand over work:** comment on the issue and add the `needs-cmo`
  label. The CMO is woken within about 5 minutes of your comment and usually replies within 15.
- **Keep the issue open and `needs-cmo` on until the CMO has replied.** Closed issues aren't
  watched, so a comment you post while closing an issue never reaches the CMO.
- **Never put `<!-- cmo -->` in your own comments.** That tag marks the CMO's comments, and the
  CMO is not woken for comments that carry it.
- **A CMO comment containing `<!-- relay -->` is a request for you to act on.** Do it and reply on
  the same issue.
- **Post analysis results, numbers and finished changes as issue comments** so the CMO can read
  them. Check the issue for existing CMO analysis before running your own queries.
- **Anything users see** (store copy, emails to users, prices, offers) still needs the owner's OK
  before it ships, whoever drafted it.
